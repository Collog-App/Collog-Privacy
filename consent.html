콜록 통화 분석 동의 안내

  • 동의서 버전: 2026-10-26.v5
  • 운영자: 임도협(Dohyeop Lim)
  • 문의 이메일: developer@collog.live

앱의 통화 분석 동의 화면에서 「자세히 보기」를 누르면 이 페이지가 열립니다. 개인정보 처리 전반은 개인정보처리방침에서 확인할 수 있습니다.

1. 통화 분석은 선택 사항입니다

  • 통화 녹음과 AI 분석은 선택 사항입니다.
  • 두 참여자가 모두 동의한 통화에서만 음성을 녹음합니다.
  • 동의하지 않아도 가족 통화는 그대로 이용할 수 있습니다.
  • 「가입 없이 둘러보기」에서는 통화·녹음·분석을 하지 않으며 외부로 보내는 정보가 없습니다.

2. 외부 AI 서비스로 보내는 정보

두 참여자가 모두 동의한 통화에 한해, 아래 서비스로 정보를 보냅니다.

받는 곳 보내는 정보 목적 설정
Deepgram 부모와 자녀의 통화 음성 대화를 글로 변환 요청에 모델 개선 참여 제외 옵션을 사용합니다.
Google Gemini 두 참여자의 전사문과 그 안의 증상, 복약, 활동, 수면 정보 건강 기록 생성 Google의 유료 서비스 데이터 처리 조건을 운영자가 확인하기 전에는 녹음과 건강 분석을 비활성화합니다.
ElevenLabs 오늘의 질문 문장. 휴대폰이 직접 요청할 때는 기기의 IP 주소가 전달됩니다. 질문 음성 생성 모델 학습 이용을 제외한 계정 설정으로 사용합니다. 사용할 수 없으면 휴대폰 기본 음성으로 재생합니다.
  • 이름, 전화번호, Apple·Google 로그인 토큰은 AI 요청에 포함하지 않습니다.
  • 대화 중에 말한 개인정보는 음성과 전사문에 포함될 수 있습니다.
  • 해외 제공사 서버에서 처리될 수 있습니다.

3. 수집 항목, 이용 목적, 보관 기간

  • 수집 항목: 통화 음성, 화자별 전사문, 증상, 복약, 활동, 수면, 음성 특징값, 질문 문장, 질문 음성 요청 시 IP 주소
  • 이용 목적: 가족 통화 기반 건강 변화 기록과 리포트 제공
  • 보관 기간: 전사문과 건강 기록은 계정 삭제 시까지 보관합니다.
  • 콜록 원본 음성은 분석 후 삭제하며, 실패하거나 남은 파일은 자동으로 정리합니다.
  • 외부 제공사의 보관 기간과 삭제 처리는 해당 계약 및 정책에 따르며 콜록 서버의 삭제와 별개입니다.

4. 가족에게 제공하는 정보

부모의 건강 기록과 음성 특징값은 가족 자녀에게 제공합니다.

5. 의료 용도가 아닙니다

콜록의 기록과 리포트는 의료 진단이나 치료 용도가 아닙니다.

6. 동의 항목

통화 분석을 사용하려면 아래 항목에 모두 동의해야 합니다.

  • 건강 민감정보 수집·이용
  • 음성 특징값 추출
  • 통화 녹음과 분석
  • 자녀와 리포트 공유
  • Deepgram, Google Gemini, ElevenLabs에 데이터 전송

7. 동의를 바꾸거나 거절하려면

  • 앱의 설정 → 「가족 공유 데이터 범위」에서 동의 내용을 확인하고 바꾸거나 철회할 수 있습니다.
  • 거절하거나 철회하면 이후 녹음과 AI 분석을 중단합니다.
  • 기존 기록 삭제는 설정 → 「계정 정보」 → 「계정 삭제」에서 요청할 수 있습니다.
